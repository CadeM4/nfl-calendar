Prefer to paste the subscription URL?

Use Copy feed URL above. On iPhone, open Calendar → Calendars → Add Calendar → Add Subscription Calendar. Paste the HTTPS URL, then choose Find → Done (or Subscribe on earlier iOS versions). In Google Calendar on the web, use Other calendars → + → From URL. In Outlook, choose Add calendar → Subscribe from web.

Choose a calendar subscription when adding the URL. Importing a downloaded file creates a one-time copy and will not receive schedule updates.

What happens with flex scheduling and TBD games?

Published changes update the same game in your subscribed calendar. A confirmed date with an unknown kickoff appears as a tentative all-day event. If the date is also unconfirmed, a clearly labeled week placeholder is used until the source publishes a date.

Playoff games are included as the source makes them available. The feed does not guess playoff matchups.

How accurate is the viewing information?

TV and streaming details are included only when reported for that game by the schedule source. A listed broadcaster does not guarantee availability in every market or subscription. Local restrictions and provider rights still apply.

Check the broadcaster before game day. An unknown broadcaster is labeled TBD.

How does this stay up to date?

The project checks for schedule updates automatically. Each successful refresh is validated before the calendar is published. If the source fails or the schedule fails validation, the last valid feed stays in place.

The timestamp on this page shows when the published schedule was retrieved. A delayed feed is flagged here so you can judge its freshness.
